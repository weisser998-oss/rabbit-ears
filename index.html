Guide

Settings

Free from Google Cloud Console: create a project, enable "YouTube Data API v3", then Credentials → Create API key. It stays in this browser only.

Pre-loaded channels play silently in the background so switching to them is instant. Each one uses about as much data as the channel you're watching.

Lineup

Your video files

Commercials

One per line: playlists, channels or single videos of commercials. Long compilations work too: each break plays a slice of one. Try searching YouTube for "90s commercials compilation". Turn breaks on for each channel in its settings above.

Sync between devices

Every device with the same lineup shows the same thing at the same time. Each broadcast day starts at 4 AM. Your lineup is shared through a lineup.json file on your GitHub site, and every device checks it when it opens.

With a token, saving here updates your other devices automatically. To make one on github.com:
  1. Your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your Rabbit Ears repository.
  3. Permissions → Contents: Read and write. Generate, copy, and paste it here.
Without a token, use Download lineup.json and upload it to your repository.

Backup

Copy your lineup as text, or paste one in to import it. The API key and token aren't included.

Videos that won't play (removed, blocked in your country, or blocked while your VPN was off) are skipped on this device and retried after a day. Retry skipped videos tries them all again now.
